# Sprints (biweekly iterations)
> status: Active — authoritative English version. Chinese translation: [README.zh.md](./README.zh.md)

- **Cadence**: one iteration every two weeks; files named `S<year>-<seq>.md` (e.g., `S2026-01.md`)
- **Four sections per sprint**: goal / scope (pulled from GitHub Issues, linked via `Closes #N`) / results / retrospective
- **Requirements live only in GitHub Issues**; no new requirements mid-sprint (bugs excepted)
- Retrospective improvements land immediately via the capture-discussions mechanism (decisions / AGENTS.md / deferred blueprints) — no verbal conclusions
