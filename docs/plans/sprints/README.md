# Sprints（双周迭代）
> status: Active（生效）

- **节奏**：双周一个迭代；文件命名 `S<年>-<两位序号>.md`（如 `S2026-01.md`）
- **每期四段**：目标 / 范围（从 GitHub Issues 领取，commit 用 `Closes #N` 关联）/ 结果 / 回顾
- **需求只进 Issues**；sprint 中途不加新需求（bug 除外）
- 回顾产出的改进项按"讨论入库机制"当场落盘（decisions / AGENTS.md / 终极方案目录），不留口头结论
