# Domain Adapter Cards
> status: Active — authoritative English version. Chinese translation: [README.zh.md](./README.zh.md)

Onboarding a new domain = filling one adapter card: answer the five fixed questions — **build / run / verify / observe / sandbox** — and land four standard scripts.

- Blank template: [adapter-card-template.md](./adapter-card-template.md)
- Card workflow: copy the template → fill it following your domain's section in [Implementation Guide Part 3](../solution/vibe-coding-harness-plan.md) → implement the four scripts → review, then register it here
- Card naming: `<domain>-<stack>.md`, e.g., `desktop-qt.md`, `embedded-stm32-freertos.md`, `backend-spring.md`
